# 数值证据的解释范围

这里保存比较对象与采集语义的边界；msprobe 格式和工具见 [数据契约](msprobe.md)。

| 材料 | 能覆盖的结论范围 |
|---|---|
| Norm/Mean/Max/Min | 对应字段的统计信息，不代表逐元素、局部位置或逐元素增益相同；小数值也不自带“噪声”含义。 |
| dump 中没有某条记录 | 仅表示当前采集范围未观测到；是否会采集该操作、窗口是否覆盖需另有依据。 |
| 本地梯度、参数分片、通信 bucket | 不同测量对象。只有切分、拼接、归约和累积关系对应后，才能比较或重建全局量。 |
| backward 输入/输出槽 | 采集器记录的端口；命名相同或槽数不同不直接证明梯度角色、计算图或参数配置相同/不同。 |
| 某版本源码或相同安装路径 | 该实现的一种可能路径；实际版本、分支与运行加载信息决定其是否适用于本次问题。 |
| 某卡/step/样本上的结论 | 只覆盖已检查对象；扩展到其他对象需要覆盖记录或明确外推依据。 |

比较结果应保留对象、字段、dtype、shape、step/rank 与来源。执行序和数量对账不额外提供数据依赖或因果关系；这些关系属于当前问题的待证边界。
