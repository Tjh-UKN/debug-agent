# 训练资料索引

需要选择相关材料时查阅；具体核查路径由当前问题决定，已有材料优先。

| 现象 | 相关材料窗口 |
|---|---|
| 首步 loss 不同 | 本次输入、初始权重与前向计算。 |
| 前期对齐，第 k 步 loss 才变化 | k−1 步梯度与参数更新，以及 k 步权重和前向计算。 |
| grad norm 先变化 | 本步局部反向、跨卡归约与参数梯度汇总，必要时关联前向状态。 |
| 异常步未知、全面 dump 成本高 | 已有趋势或轻量监控用于确定时间段；模块、API 与局部 tensor 分别覆盖不同粒度。 |

环境事实：跨设备同 seed 不保证同一随机张量；增加 dump、同步或改变 overlap 会影响执行时序；缩减卡数可能联动 batch、并行切分及通信。对照是否保留原问题，由本次材料与运行结果判断。

官方参考：[Ascend/msprobe 训练精度定位指南](https://gitcode.com/Ascend/msprobe/blob/master/docs/en/best_practices/train_debug_guide.md)。§2.2.4 介绍缩减，§2.3 分场景定位，§2.4 单算子验证，§4.2 工具选择。具体采集接口与配置按目标安装版本核对；官方案例中的阈值、开关和修复方式不是本项目的通用要求。
